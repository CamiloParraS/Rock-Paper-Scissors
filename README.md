# Rock-Paper-Scissors

A simple Rock-Paper-Scissors game built with HTML, CSS, and JavaScript for [The Odin Project](https://www.theodinproject.com/) - JavaScript Foundations. This version features a graphical user interface (GUI) to play the game.

## How to Play

1.  Open `index.html` in your browser.
2.  Click on one of the buttons: "Rock", "Paper", or "Scissors" to make your choice.
3.  The computer will make its choice, and the round's result will be displayed on the screen.
4.  The scores and current round number are updated after each round.
5.  The game continues until either you or the computer scores 5 points.
6.  The final winner is announced on the screen, and the game buttons are disabled.

## How it Works

-   The user interface is built with HTML and styled with CSS.
-   JavaScript is used to handle the game logic.
-   Event listeners on the buttons capture the player's choice.
-   The DOM is updated dynamically to show scores, round results, and the final winner.

## Running the Game

1.  Clone or download this repository.
2.  Open `index.html` in your web browser.
3.  Play the game using the on-screen buttons!
